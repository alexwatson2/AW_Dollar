# dollar برای اندروید

نسخهٔ بومی Android با Java و ابزارهای خود اندروید؛ مستقل از نسخهٔ Windows. حداقل Android 6 (API 23).

## امکانات

نام قابل مشاهدهٔ برنامه و ویجت دقیقاً **dollar** است؛ applicationId برای حفظ سازگاری نصب قبلی تغییر نکرده است.

- داخل برنامه، بخش **مقایسهٔ همهٔ APIها** قیمت دلار و یورو از هر سه API، زمان نرخ، زمان پاسخ، خطا و قیمت ذخیره‌شدهٔ قبلی را جداگانه نشان می‌دهد. شکست یک API، قیمت منابع دیگر را حذف نمی‌کند.
- اولین پاسخ معتبر هر ارز همان لحظه روی ویجت منتشر می‌شود؛ کندترین منبع، نمایش نتیجه را معطل نمی‌کند. نرخ قدیمی‌تر از نرخ منتخب قبلی یا بیش از ۷ روز، برنده نمی‌شود؛ در برنامه برای مقایسه قابل مشاهده است.
- هنگام تغییر منبع، ویجت خط تیره می‌گذارد و برنامه توضیح می‌دهد اختلاف منبع الزاماً نوسان بازار نیست. نمودار نیز بین منابع متفاوت خط نمی‌کشد.

- **یک ویجت جمع‌وجور دلار و یورو** با دو ردیف روی زمینهٔ تیره، پرچم‌های گرد، قیمت سفید و خوانا و نشان کوچک افزایش/کاهش/ثبات؛ مشابه نوار قیمت ویندوز. نام ارز، واحد، مقدار تغییر و متن وضعیت در ویجت نمایش داده نمی‌شود؛ قیمت‌ها به تومان‌اند.
- لمس ردیف دلار یا یورو → باز شدن تاریخچهٔ همان ارز. یک تاریخ و ساعت کوچک زیر دو ردیف نمایش داده می‌شود؛ تاریخ، زمان قدیمی‌ترِ دو نرخ منبع است تا نرخ قدیمی با زمان دریافت جدید اشتباه نشود. در صورت قطع دریافت یک ارز، زمان تازهٔ ارز دیگر جای زمان قدیمی را نمی‌گیرد. اگر هنوز هیچ نرخی نداریم، فقط خط تیره نشان داده می‌شود.
- نمایش آخرین نرخ، زمان اعلام **منبع** و زمان **دریافت گوشی**، نمودار ۶۰ ثبت اخیر و تاریخچهٔ صفحه‌بندی‌شده (۵۰ ردیف در صفحه).
- تمام snapshotهای دریافتی معتبر در SQLite نگهداری می‌شوند. نرخ و زمان منبع یکسان دوباره ذخیره نمی‌شود؛ قیمت یکسان در زمان جدید ثبت می‌شود. سقف یا پاک‌سازی خودکار تاریخچه وجود ندارد.
- افزایش / کاهش / بدون تغییر نسبت به رکورد قبلی، نه تغییر روزانهٔ بازار. اولین ثبت بدون تغییر ساختگی نمایش داده می‌شود.
- خروجی CSV از **تمام سوابق هر دو ارز** با زمان UTC، قیمت و تغییر به تومان؛ محل ذخیره را خودتان انتخاب می‌کنید، بدون مجوز دسترسی کلی به حافظه.
- حالت قطع اینترنت: دادهٔ قبلی باقی می‌ماند. جزئیات «ذخیره‌شده / قدیمی» داخل برنامه است؛ در ویجت فقط رنگ تاریخ کمی گرم‌تر می‌شود و توضیح وضعیت برای TalkBack وجود دارد. خطای یک ارز مانع ذخیرهٔ ارز دیگر نمی‌شود.

## دریافت APK

این مخزن فعلاً **کد نسخهٔ اندروید** را دارد؛ APK از پیش ساخته‌شده همراه سورس نیست.

بعد از push تغییرات به GitHub، workflow با نام **Android APK** در تب Actions، تست و lint و ساخت را اجرا می‌کند. بعد از اجرای موفق، فایل **AW-Dollar-Android-debug** را از Artifacts دانلود و از ZIP خارج کنید. `app-debug.apk` برای تست قابل نصب است. این APK دیباگ است، نه نسخهٔ امضاشدهٔ انتشار در فروشگاه. ارسال هر build دیباگ CI می‌تواند کلید موقت متفاوتی داشته باشد؛ برای به‌روزرسانی‌های واقعی بدون حذف داده، از ابتدا از یک کلید امضای ثابت و امن استفاده کنید. نصب APK با کلید متفاوت روی نصب قبلی شکست می‌خورد؛ برای حفظ تاریخچه برنامهٔ قبلی را حذف نکنید و ابتدا CSV بگیرید.

برای انتشار عمومی، در Android Studio از **Generate Signed Bundle / APK** استفاده کنید. فایل کلید و رمز را خارج مخزن نگه دارید. برای به‌روزرسانی همان نصب، applicationId، کلید امضا و نسخهٔ افزایشی را حفظ کنید.

## ساخت محلی

1. Android Studio به‌روز، JDK 21، Android SDK 35 و Build Tools 35.0.0 نصب کنید.
2. پوشهٔ **android/** را به‌عنوان پروژه باز کنید (نه فایل Solution ویندوز).
3. Gradle Sync و سپس Run را روی گوشی واقعی یا شبیه‌ساز اجرا کنید.

یا از خط فرمان:

```sh
cd android
# SDK را با ANDROID_HOME یا sdk.dir در local.properties مشخص کنید.
./gradlew testDebugUnitTest lintDebug assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

روی ویندوز از `gradlew.bat` استفاده کنید. برای ابزارهای جدید sdkmanager از JDK 21 استفاده کنید؛ کد برنامه همچنان Java 17 است. دریافت اولیهٔ ابزارهای Gradle/Google Maven/Android SDK به اینترنت نیاز دارد.

## استفاده روی گوشی

1. برنامه را باز کنید و یک بار «به‌روزرسانی قیمت‌ها» را بزنید.
2. «افزودن ویجت» را لمس کنید؛ از هر تب برنامه، **همان یک ویجت دلار و یورو** اضافه می‌شود. تأیید نهایی با لانچر گوشی است.
3. اگر لانچر افزودن مستقیم را پشتیبانی نمی‌کند، روی فضای خالی صفحهٔ اصلی نگه دارید → **ویجت‌ها** → **dollar** را روی صفحه بگذارید. اندازهٔ پیشنهادی **۲×۱** است (اندازهٔ واقعی به لانچر بستگی دارد) و عرض قابل تغییر است.
4. روی ردیف مورد نظر بزنید تا تاریخچهٔ همان ارز باز شود.

**ارتقا از نسخهٔ دو کارت:** ویجت دلار قبلی هر دو ارز را نشان می‌دهد، ولی لانچر ممکن است فضای ۲×۲ قدیمی را حفظ کند؛ آن را از صفحه بردارید و ویجت جدید را دوباره اضافه کنید تا ۲×۱ شود. ویجت مستقل یورو حذف شده؛ اگر جای خالی/خطای ویجت یورو قبلی روی صفحه ماند، فقط همان ویجت را بردارید. برداشتن ویجت، تاریخچهٔ برنامه را پاک نمی‌کند. برای حفظ تاریخچه، خود برنامه را حذف نکنید؛ هشدار امضای APK در بخش دریافت APK را هم بخوانید.

هیچ مجوز اعلان، مخاطب، مکان، یا نمایش روی برنامه‌های دیگر لازم نیست. ویجت متعلق به **صفحهٔ اصلی** است، نه پنجرهٔ شناور روی همهٔ برنامه‌ها.

## ثبت تاریخچه و محدودیت واقعی اندروید

- JobScheduler هر حدود **۳۰ دقیقه** با اینترنت کار می‌کند و بعد از راه‌اندازی مجدد گوشی هم زمان‌بندی حفظ می‌شود. خاموشی گوشی، Doze، محدودیت باتری، توقف اجباری برنامه و اینترنت می‌تواند اجرا را عقب بیندازد؛ ثبت تک‌تک نوسانات بازار تضمین نمی‌شود. بعد از Force stop باید برنامه دوباره باز شود.
- برنامه تاریخچه را **از اولین دریافت روی همین گوشی** ثبت می‌کند؛ دادهٔ ازدست‌رفتهٔ زمان خاموشی و سابقهٔ قبل از نصب از API وارد نمی‌شود.
- سه منبع هم‌زمان بررسی می‌شوند: **PriceToDay، Iran Market Data و نرخ‌سنج**. جزئیات مسیرها، واحدها و سیاست انتخاب در [SOURCES.md](SOURCES.md) آمده است. قیمت رسمی/بانکی و تتر جایگزین دلار آزاد نمی‌شوند. اعداد نمونه فقط در تست‌ها هستند، نه در محصول.
- تاریخ داخل برنامه **میلادی** و ساعت مطابق تنظیم گوشی است؛ CSV زمان UTC دارد. برنامه تقویم شمسی پیاده‌سازی نکرده است.
- داده‌ها در حافظهٔ خصوصی برنامه‌اند و به سرور خودمان ارسال نمی‌شوند؛ فراخوانی دریافت قیمت مستقیماً به سرویس عمومی می‌رود. Android Backup خاموش است. حذف برنامه/پاک کردن داده، تاریخچه را پاک می‌کند. برای آرشیو CSV بگیرید؛ وارد کردن مجدد CSV هنوز پیاده‌سازی نشده است.
- برچسب «قدیمی» یعنی بیش از یک ساعت از زمان منبع گذشته یا آخرین درخواست خطا داشته؛ تعطیلی بازار نیز ممکن است چنین حالتی بسازد.

## ساختار و تست

- `PriceApi` / `PriceSource`: سه adapter با HTTPS، timeout، اعتبارسنجی قیمت، واحد و زمان؛ بدون API key.
- `SourceRace`: درخواست‌های موازی، اولین پاسخ معتبر برای هر ارز، ادامهٔ منابع دیگر برای مقایسه و سقف مهلت ۱۸ ثانیه.
- `SourceTime`: تبدیل تاریخ شمسی نرخ‌سنج به زمان UTC با منطقهٔ تهران.
- `SourceSnapshot`: آخرین قیمت معتبر هر API به‌همراه وضعیت آخرین تلاش، خطا و زمان پاسخ.
- `PriceStore`: SQLite نسخهٔ ۲؛ ارتقای غیرمخرب داده‌های قبلی، شناسهٔ منبع در تاریخچه، آرشیو تمام پاسخ‌های معتبر و cache/status مستقل هر API. تاریخچهٔ روی صفحه مربوط به نرخ‌های منتخب ویجت است؛ CSV تمام نرخ‌های ثبت‌شدهٔ همهٔ منابع را با ستون source و اختلاف در همان منبع صادر می‌کند.
- `Refresh` / `RefreshJobService`: اجرای شبکه خارج از thread رابط کاربری، زمان‌بندی ماندگار و لغو job.
- `DollarWidget` / `PriceWidget`: یک provider و یک RemoteViews شامل دو ارز؛ نام component قبلی دلار برای ارتقای نصب‌های موجود حفظ شده است. هر ردیف PendingIntent مستقل و غیرقابل‌تغییر دارد.
- `WidgetSummary`: نشان مختصر روند و انتخاب تاریخ صادقانه برای نرخ‌های هم‌زمان یا ناقص؛ بدون متن اضافه روی ویجت.
- `MainActivity` / `TrendChart`: رابط راست‌به‌چپ، تاریخچه، نمودار و CSV با Storage Access Framework.
- `app/src/test`: تست تبدیل دقیق پول، جهت تغییر، اعتبارسنجی مدل، زمان‌های UTC/offset/fractional و نمایش مختصر ویجت (اولین دریافت، ثبات، رشد، افت، دریافت ناقص و تاریخ قدیمی‌تر).
- `.github/workflows/android.yml`: ساخت APK و تست/lint در محیط دارای SDK.

در محیط اولیهٔ توسعهٔ لینوکسی این تغییرات، JDK و Android SDK نصب نبود و دسترسی به سرویس قیمت و مخازن Google محدود بود؛ بنابراین ساخت APK و تست روی دستگاه در آن محیط انجام نشده است. قبل از انتشار، workflow و چک‌لیست زیر باید روی محیط اندروید اجرا شوند.

### چک‌لیست تست دستگاه

- [ ] اولین اجرا آنلاین: هر دو ارز ذخیره شوند؛ قیمت ریال ÷۱۰ درست باشد.
- [ ] قطع اینترنت و زدن refresh: قیمت قبلی پاک نشود، وضعیت قدیمی نمایش یابد.
- [ ] دو بار دریافت snapshot یکسان: تعداد رکورد زیاد نشود.
- [ ] دریافت قیمت بالاتر/پایین‌تر: علامت و اختلاف در برنامه و ویجت مطابق تاریخچه باشد.
- [ ] فقط یک گزینهٔ ویجت در فهرست باشد؛ دو ارز داخل همان ویجت ۲×۱، پرچم‌ها، اعداد و تاریخ بدون بریدگی خوانا باشند.
- [ ] لمس جداگانهٔ دو ردیف، ارز درست را باز کند؛ تغییر عرض، فونت بزرگ و ارتقا از ویجت قدیمی بررسی شوند.
- [ ] بستن برنامه و restart گوشی: ویجت و دیتابیس بمانند؛ دریافت پس‌زمینه بررسی شود.
- [ ] Android 6 و Android 15+، فونت بزرگ، حالت افقی، لانچرهای مختلف و حاشیه‌های system bars بررسی شوند.
- [ ] بیش از ۵۰ رکورد: صفحه‌بندی، اختلاف با رکورد صفحهٔ بعد و CSV کامل بررسی شوند.
- [ ] لغو ذخیرهٔ فایل/خطای حافظه و چرخش گوشی هنگام دریافت بدون crash مدیریت شوند.

### تست چندمنبعی

- تست fixture واقعی Iran Market، پاسخ نرخ‌سنج و PriceToDay؛ تبدیل دقیق واحد، تشخیص بازار نادرست، تاریخ آینده و تاریخ شمسی کبیسه.
- تست اولین پاسخ معتبر، رد پاسخ نامعتبر/قدیمی، ادامهٔ بررسی منبع کند، شکست همهٔ منابع و لغو پس از timeout.
- `ci/check_database.py`: اجرای SQL واقعی مهاجرت دیتابیس روی SQLite و بررسی حفظ شناسه، قیمت، تاریخ، جداسازی منبع و cache هنگام خطا.
- روی گوشی: یک API را مسدود کنید و موفقیت بقیه، نمایش سریع ویجت، مقایسهٔ هر سه منبع، تغییر منبع بدون فلش کاذب و CSV شامل source را بررسی کنید.
