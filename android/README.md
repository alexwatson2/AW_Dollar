# AW Dollar برای اندروید

نسخهٔ بومی Android با Java و ابزارهای خود اندروید؛ مستقل از نسخهٔ Windows. حداقل Android 6 (API 23).

## امکانات

- دو ویجت مستقل **دلار** و **یورو** برای صفحهٔ اصلی، کارت روشن با گوشهٔ گرد، پرچم، قیمت درشت به تومان و تغییر نسبت به ثبت قبلی.
- لمس تمام سطح ویجت → باز شدن برنامه روی همان ارز.
- نمایش آخرین نرخ، زمان اعلام **منبع** و زمان **دریافت گوشی**، نمودار ۶۰ ثبت اخیر و تاریخچهٔ صفحه‌بندی‌شده (۵۰ ردیف در صفحه).
- تمام snapshotهای دریافتی معتبر در SQLite نگهداری می‌شوند. نرخ و زمان منبع یکسان دوباره ذخیره نمی‌شود؛ قیمت یکسان در زمان جدید ثبت می‌شود. سقف یا پاک‌سازی خودکار تاریخچه وجود ندارد.
- افزایش / کاهش / بدون تغییر نسبت به رکورد قبلی، نه تغییر روزانهٔ بازار. اولین ثبت بدون تغییر ساختگی نمایش داده می‌شود.
- خروجی CSV از **تمام سوابق هر دو ارز** با زمان UTC، قیمت و تغییر به تومان؛ محل ذخیره را خودتان انتخاب می‌کنید، بدون مجوز دسترسی کلی به حافظه.
- حالت قطع اینترنت: دادهٔ قبلی باقی می‌ماند و با برچسب «ذخیره‌شده / قدیمی» نمایش داده می‌شود. خطای یک ارز مانع ذخیرهٔ ارز دیگر نمی‌شود.

## دریافت APK

این مخزن فعلاً **کد نسخهٔ اندروید** را دارد؛ APK از پیش ساخته‌شده همراه سورس نیست.

بعد از push تغییرات به GitHub، workflow با نام **Android APK** در تب Actions، تست و lint و ساخت را اجرا می‌کند. بعد از اجرای موفق، فایل **AW-Dollar-Android-debug** را از Artifacts دانلود و از ZIP خارج کنید. `app-debug.apk` برای تست قابل نصب است. این APK دیباگ است، نه نسخهٔ امضاشدهٔ انتشار در فروشگاه. ارسال هر build دیباگ CI می‌تواند کلید موقت متفاوتی داشته باشد؛ برای به‌روزرسانی‌های واقعی بدون حذف داده، از ابتدا از یک کلید امضای ثابت و امن استفاده کنید. نصب APK با کلید متفاوت روی نصب قبلی شکست می‌خورد؛ برای حفظ تاریخچه برنامهٔ قبلی را حذف نکنید و ابتدا CSV بگیرید.

برای انتشار عمومی، در Android Studio از **Generate Signed Bundle / APK** استفاده کنید. فایل کلید و رمز را خارج مخزن نگه دارید. برای به‌روزرسانی همان نصب، applicationId، کلید امضا و نسخهٔ افزایشی را حفظ کنید.

## ساخت محلی

1. Android Studio به‌روز، JDK 17، Android SDK 35 و Build Tools 35.0.0 نصب کنید.
2. پوشهٔ **android/** را به‌عنوان پروژه باز کنید (نه فایل Solution ویندوز).
3. Gradle Sync و سپس Run را روی گوشی واقعی یا شبیه‌ساز اجرا کنید.

یا از خط فرمان:

```sh
cd android
# SDK را با ANDROID_HOME یا sdk.dir در local.properties مشخص کنید.
./gradlew testDebugUnitTest lintDebug assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

روی ویندوز از `gradlew.bat` استفاده کنید. دریافت اولیهٔ ابزارهای Gradle/Google Maven/Android SDK به اینترنت نیاز دارد.

## استفاده روی گوشی

1. برنامه را باز کنید و یک بار «به‌روزرسانی قیمت‌ها» را بزنید.
2. ارز مورد نظر را انتخاب و «افزودن ویجت» را لمس کنید؛ تأیید نهایی با لانچر گوشی است.
3. اگر لانچر افزودن مستقیم را پشتیبانی نمی‌کند، روی فضای خالی صفحهٔ اصلی نگه دارید → **ویجت‌ها** → **AW Dollar** → دلار یا یورو را روی صفحه بگذارید. اندازهٔ پیشنهادی ۲×۲ است؛ امکان تغییر اندازه وجود دارد.
4. روی ویجت بزنید تا برنامه و تاریخچهٔ همان ارز باز شود.

هیچ مجوز اعلان، مخاطب، مکان، یا نمایش روی برنامه‌های دیگر لازم نیست. ویجت متعلق به **صفحهٔ اصلی** است، نه پنجرهٔ شناور روی همهٔ برنامه‌ها.

## ثبت تاریخچه و محدودیت واقعی اندروید

- JobScheduler هر حدود **۳۰ دقیقه** با اینترنت کار می‌کند و بعد از راه‌اندازی مجدد گوشی هم زمان‌بندی حفظ می‌شود. خاموشی گوشی، Doze، محدودیت باتری، توقف اجباری برنامه و اینترنت می‌تواند اجرا را عقب بیندازد؛ ثبت تک‌تک نوسانات بازار تضمین نمی‌شود. بعد از Force stop باید برنامه دوباره باز شود.
- برنامه تاریخچه را **از اولین دریافت روی همین گوشی** ثبت می‌کند؛ دادهٔ ازدست‌رفتهٔ زمان خاموشی و سابقهٔ قبل از نصب از API وارد نمی‌شود.
- منبع همان `https://api.priceto.day/v1/latest/irr/usd` و `/euro` است؛ مقدار ریال به تومان تبدیل می‌شود. عدد نمونه یا نرخ نمایشی ساختگی در محصول وجود ندارد. زمان منبع معتبر و دارای timezone لازم است؛ پاسخ نامعتبر ذخیره نمی‌شود.
- تاریخ داخل برنامه **میلادی** و ساعت مطابق تنظیم گوشی است؛ CSV زمان UTC دارد. برنامه تقویم شمسی پیاده‌سازی نکرده است.
- داده‌ها در حافظهٔ خصوصی برنامه‌اند و به سرور خودمان ارسال نمی‌شوند؛ فراخوانی دریافت قیمت مستقیماً به سرویس عمومی می‌رود. Android Backup خاموش است. حذف برنامه/پاک کردن داده، تاریخچه را پاک می‌کند. برای آرشیو CSV بگیرید؛ وارد کردن مجدد CSV هنوز پیاده‌سازی نشده است.
- برچسب «قدیمی» یعنی بیش از یک ساعت از زمان منبع گذشته یا آخرین درخواست خطا داشته؛ تعطیلی بازار نیز ممکن است چنین حالتی بسازد.

## ساختار و تست

- `PriceApi`: HTTPS با timeout، اعتبارسنجی قیمت و timestamp، بدون API key.
- `PriceStore`: SQLite، یکتایی snapshot، ترتیب زمانی و صفحه‌بندی.
- `Refresh` / `RefreshJobService`: اجرای شبکه خارج از thread رابط کاربری، زمان‌بندی ماندگار و لغو job.
- `DollarWidget` / `EuroWidget`: RemoteViews و PendingIntent غیرقابل‌تغییر برای باز شدن ارز درست.
- `MainActivity` / `TrendChart`: رابط راست‌به‌چپ، تاریخچه، نمودار و CSV با Storage Access Framework.
- `app/src/test`: تست تبدیل دقیق پول، جهت تغییر، اعتبارسنجی مدل و زمان‌های UTC/offset/fractional.
- `.github/workflows/android.yml`: ساخت APK و تست/lint در محیط دارای SDK.

در محیط اولیهٔ توسعهٔ لینوکسی این تغییرات، JDK و Android SDK نصب نبود و دسترسی به سرویس قیمت و مخازن Google محدود بود؛ بنابراین ساخت APK و تست روی دستگاه در آن محیط انجام نشده است. قبل از انتشار، workflow و چک‌لیست زیر باید روی محیط اندروید اجرا شوند.
