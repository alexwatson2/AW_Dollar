# منابع نرخ در dollar

این‌ها سه **مسیر دریافت مستقل** هستند، نه لزوماً سه بازار یا سه تولیدکنندهٔ دادهٔ متفاوت. PriceToDay و Iran Market از TGJU استفاده می‌کنند؛ یکی بودن قیمت‌ها طبیعی است و توافق آن‌ها تأیید مستقل بازار محسوب نمی‌شود. سرویس‌های رایگان ممکن است قطع شوند یا قالب پاسخشان عوض شود.

## APIهای پیاده‌سازی‌شده

| نام داخل برنامه | مسیر عمومی HTTPS | واحد ورودی / زمان |
| --- | --- | --- |
| PriceToDay | `https://api.priceto.day/v1/latest/irr/usd` و `/euro` | ریال؛ فیلد `time` با timezone |
| Iran Market Data | `https://api.github.com/repos/iran-market/iran-market.github.io/contents/data/popular.json` با `Accept: application/vnd.github.raw+json` | نمادهای `USD_IRR_FREE` و `EUR_IRR_FREE`؛ `currency=IRT` تومان یا `IRR` ریال، `market=iran_free`، `unit_size=1`؛ زمان `timestamp` خود آیتم، نه زمان انتشار فایل |
| نرخ‌سنج / Nerkhsanj | `https://nerkh.jahankhahan.shop/data/live.json` | `rates.dollar` و `rates.euro` به تومان؛ `date` شمسی و `time` در منطقهٔ تهران |

همهٔ قیمت‌ها در حافظه به ریال صحیح و در UI به تومان تبدیل می‌شوند. اعشار تومان حفظ می‌شود؛ قیمت غیرمثبت، سرریز، واحد ناشناخته، ارز مفقود یا timestamp نامعتبر/آینده رد می‌شود. نرخ رسمی و تتر با دلار نقدی بازار آزاد مخلوط نمی‌شوند. تبدیل تاریخ شمسی به‌صورت محلی برای سال‌های ۱۳۰۰ تا ۱۴۹۹ و با اعتبارسنجی کبیسه انجام می‌شود.

**مراجع قرارداد و نمونهٔ پاسخ:**

- [PriceToDay / pricedb](https://github.com/margani/pricedb) و `openapi.yaml`
- [Iran Market Data](https://github.com/iran-market/iran-market.github.io) و فایل `data/popular.json`؛ fixture واقعی کوچک در `app/src/test/resources/iran-market.json` برای تست ذخیره شده، دادهٔ محصول نیست.
- [راهنمای نرخ‌سنج](https://github.com/hamidjh80-arch/nerkhsanj-api)؛ fixture حداقلی از خروجی زنده در `app/src/test/resources/nerkhsanj.json`.

در ۲۰۲۶/۱۱/۰۸ خروجی JSON عمومی هر سه مسیر بررسی شد. دسترس‌پذیری از اینترنت/اپراتور گوشی تضمین‌شده نیست. برای GitHub از API عمومی بدون توکن استفاده می‌شود؛ سهمیهٔ بدون احراز هویت معمولاً ۶۰ درخواست در ساعت برای هر IP است. هیچ کلید یا credential در اپ تعبیه نشده است. وضعیت HTTP/قطع اتصال در کارت همان API نمایش داده می‌شود و بقیهٔ منابع ادامه می‌دهند.

## انتخاب سریع بدون نمایش اطلاعات اضافه روی ویجت

- شش درخواست (سه منبع × دو ارز) به‌طور موازی اجرا می‌شوند. درخواست‌های دو ارز مستقل‌اند تا معطل شدن یورو، دلار را معطل نکند. منابع bulk در این نسخه برای هر ارز یک درخواست مجزا دارند.
- اولین **پاسخ معتبر و مجاز** هر ارز انتخاب و فوراً در ویجت منتشر می‌شود. پاسخ دیرتر همان دور، نرخ منتخب را عوض نمی‌کند ولی در بخش مقایسه و آرشیو ذخیره می‌شود.
- نرخ قدیمی‌تر از آخرین نرخ منتخب آن ارز یا قدیمی‌تر از ۷ روز برنده نمی‌شود؛ این پاسخ در برنامه با زمان واقعی‌اش قابل دیدن است. این سیاست جلوی عقب رفتن زمان ویجت توسط یک mirror سریع اما عقب‌افتاده را می‌گیرد.
- timeout اتصال/خواندن ۶ ثانیه، سقف خواندن پاسخ و سقف اندازهٔ ۱ MiB وجود دارد. مهلت هماهنگ‌کنندهٔ هر دور ۱۸ ثانیه است؛ taskهای باقیمانده لغو می‌شوند. لغو socketهای Android لزوماً فوری نیست، ولی نتیجهٔ دیررس وارد دور بعد نمی‌شود.
- UI خواندن دیتابیس و thread هماهنگ‌کنندهٔ شبکه جدا هستند؛ قیمت APIهای تمام‌شده هنگام ادامهٔ بررسی سایر APIها قابل مشاهده است.
- اگر همهٔ منابع ناموفق/نامعتبر باشند، قیمت آخر پاک یا صفر نمی‌شود. اگر فقط یک ارز موفق باشد، همان ردیف به‌روز می‌شود و ردیف دیگر ذخیره‌شده می‌ماند.
- انتخاب برای دلار و یورو مستقل است؛ ممکن است منبع منتخب آن‌ها متفاوت باشد. تغییر منبع باعث فلش کاذب «نوسان بازار» نمی‌شود.
- ظاهر ویجت همان دو ردیف کوچک و تاریخ می‌ماند؛ نام/وضعیت/URL/سرعت و مقایسه فقط داخل برنامه است.

## داده‌ها و حفظ تاریخچه

مهاجرت SQLite از نسخهٔ ۱ به ۲ رکوردهای قبلی، شناسه‌ها، زمان‌ها و قیمت‌ها را با برچسب `pricetoday` حفظ می‌کند. قیمت معتبر هر API در `source_history` آرشیو می‌شود. `source_latest` آخرین پاسخ معتبر هر API و `source_status` نتیجهٔ آخرین تلاش را جدا نگه می‌دارند؛ خطا cache قبلی را حذف نمی‌کند. `quotes` تاریخچهٔ انتخاب‌های ویجت را نگه می‌دارد. CSV از آرشیو همهٔ منابع صادر می‌شود، با ستون `source`؛ اختلاف فقط در همان جفت ارز/منبع محاسبه می‌شود.

نام برنامه فقط `dollar` شده؛ applicationId و نام فایل دیتابیس تغییر نکرده‌اند. ارتقای بدون حذف اطلاعات نیازمند همان کلید امضای نصب قبلی است؛ APKهای debug ساخته‌شده روی runnerهای متفاوت ممکن است امضای متفاوت داشته باشند. پیش از حذف هر نصب، خروجی CSV بگیرید؛ حذف ویجت از صفحه تاریخچه را حذف نمی‌کند، ولی حذف خود برنامه می‌کند.
